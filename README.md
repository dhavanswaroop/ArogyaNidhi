# ArogyaNidhi

A modern Android application for simplified health management — store records, track appointments, and monitor child growth in one place.

---

## Features

- User authentication and profile management
- Health record storage and tracking
- Appointment scheduling and reminders
- Child growth monitoring
- Clean, responsive UI

---

## Tech Stack

| Component    | Technology     |
|--------------|----------------|
| Language     | Kotlin         |
| Platform     | Android SDK    |
| UI           | XML Layouts    |
| Architecture | MVVM           |

---

## Setup

**Clone and run:**

```bash
git clone https://github.com/dhavanswaroopsr/ArogyaNidhi.git
```

1. Open the project in Android Studio
2. Wait for Gradle sync to complete
3. Click **Run** to launch the app

---

## Project Structure

```
com.example.arogyanidhi
├── ui/        Activities and UI logic
├── data/      Models and data handling
├── adapter/   RecyclerView adapters
└── utils/     Helper classes
```
